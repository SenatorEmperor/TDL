## 💡 Project Overview

This is a **clean, foundational To-Do List web application** built using standard front-end technologies. The core functionality is the robust use of **browser Local Storage** to ensure that all tasks—whether added, marked complete, or deleted—are persisted across page refreshes and browser sessions.

---

## ✨ Key Features

* **Task Persistence:** Tasks are automatically saved to the browser's **Local Storage**, eliminating the need for a backend.
* **CRUD Operations:** Full functionality to **Create** (add), **Read** (view), **Update** (mark complete), and **Delete** tasks.
* **Intuitive Design:** A simple and responsive interface for easy task management on any device.
